About This Project

A data science project that predicts dropout risk for distance-learning students — built by a distance-learning student herself.

The Project

Vital Signs was built as a portfolio project to show a complete data science pipeline — from raw data to a trained model to a live, working product. It focuses on a problem the creator knows personally: dropping out of a distance-learning program often happens quietly, with no one noticing until it's too late.

What It Does

  • ✓Predicts dropout risk from 11 engagement signals
  • ✓Explains which factors are driving each student's score
  • ✓Runs entirely in the browser — no server, no cost
  • ✓Works in both English and Urdu

    How the data works

    Real student records aren't available for a project like this, so this uses realistic made-up data instead — built to match patterns that real research on distance learning has found. A real version would need permission from a university to use actual student data.

    Why it's free to host

    The model's math runs right inside your browser — there's no server doing the work behind the scenes. That means no hosting cost, and the score updates instantly as you move a slider.

    Model Report Card — the honest numbers

    A model is only as trustworthy as the numbers behind it. Here's exactly how this one performs on students it wasn't trained on — including where it struggles.

    ⚠️ Honest limitation: this model catches less than half of actual at-risk students (recall ~46%). It's better used as one signal for advisors alongside human judgment, not a replacement for it.
